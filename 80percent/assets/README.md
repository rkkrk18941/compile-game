# Currency artwork

Generated with the built-in `image_gen` tool. The complete prompts are in `prompts.json`.

- `notes.webp`: 2 columns × 3 rows; front/back of fictional 10000, 5000 and 1000 game banknotes. Marked GAME TOKEN.
- `coins.webp`: 2 × 2; 500, 100, 50 and 10 coin faces.

The character is a procedural 3D humanoid built in `scene.js`. It does not use a photographic cutout.
The original procedural currency artwork is retained as a fallback when an image fails to load.
