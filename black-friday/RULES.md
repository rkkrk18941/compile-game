# ブラックフライデー（2023年新版のルール）仕様

ブラウザ版 `black-friday/` が実装しているルールと、その根拠です。
資料の確認日は 2026-10-19 です。各項目の［ ］は下の「出典」の番号です。
ルールの判定はすべて `engine.js` にあり、`tools/blackfriday-rules-test.mjs`（1968項目）で確かめています。

## 対象と版

- 原作はフリードマン・フリーゼのボードゲーム『Black Friday』（2F-Spiele）です。2010年の初版のあと、2023年に新版が出ました（英語版 Rio Grande Games）［1］［2］［3］。
- 日本語版はサニーバードから2024年1月26日発売。2〜5人、55分、15歳以上［4］［5］。
- 新版では初版の借金がなくなり、株価が整理され、NPCの「M.I.B.S.」が加わりました［4］。
- このブラウザ版は **新版** のルールで作っています。英語版［1］とドイツ語の原文［2］の両方を読み、食い違いや言葉の足りない所はドイツ語版で確かめました。

## 用具（ブラウザ版の数）

- 株：紫・黄・緑・青・白 各25個、黒15個。色の順番（市場の並び）は 紫 → 黄 → 緑 → 青 → 白［1］［2］。
- お金：はじめ各自 $100。金の延べ棒は終了時に1本 $100［1］。
- 株価表（7列×13行）、金価格トラック、株の購入トラック、金の購入トラック、株の売却トラック3段、レベルタイル、ボーナスタイル（2.〜5.）、袋。

## 準備

1. 市場に各色4株（5席のときは5株）。2〜4席のときは各色1株を箱に戻します［1］。
2. 売却トラック3段に、各色2株ずつ（1段10株）。黒は、株価表の右のレベル1〜9に1個ずつ（9個）、売却トラックの横に上の段から1・2・3個（6個）［1］。
3. 残りの株（各色14株）を袋へ。袋にははじめ黒は入りません［1］。
4. 袋から20株を引いて市場へ。5色の株価トークンを $8 に置き、市場の株がいちばん少ない色を右へ1マス（$10）、いちばん多い色を左へ1マス（$6）。同数ならその色すべてを動かし、5色とも同数なら動かしません［1］［2］。
5. 各自（M.I.B.S.も）袋から5株を引いて手元へ（ついたての中）、$100 を受け取ります［1］。
6. 金価格は $20、金の購入数は0［1］。
7. スタートプレイヤーはボーナスタイルを持たず、2番目以降の人が 2.、3.、4.、5. を受け取ります。M.I.B.S. がいるときは M.I.B.S. がスタートプレイヤーです［2］。
8. 席が5つ（M.I.B.S.込み）のときは、購入トラックは6マス、売却トラックは残り4つで相場変動です［1］。

## 手番：3つのアクションから1つ

- **株を買う**：今の株価で、レベルの上限まで買います（0株でもよい）。そのあと、買った色を1株、市場から「株の購入」トラックへ置きます。複数の色を買ったらそのうちのどれか、買った色が市場に残っていなければ好きな色、0株なら好きな色です［1］［2］。
- **株を売る**：今の株価で、上限まで売ります（0株でもよい）。売った株は市場へ。そのあと、今の売却トラックから売った色を1株取って市場へ戻し、その色を **左へ1マス** 下げます。売った色がトラックになければ好きな色、0株なら好きな色です［1］［2］。
- **金を買う**：今の金価格で、上限まで延べ棒を買います（0本でもよい）。「金の購入数」を買った本数だけ進めます。そのあと、好きな色を1株、市場から「金の購入」トラックへ置きます［1］［2］。

### その場の値動き

- 株を買う・金を買うで、市場からある色の **最後の1株** がなくなったら、その色は右へ1マス上がります。売却トラックの補充で最後の1株がなくなったときも同じです［2］。
- 購入トラック（株・金それぞれ）に同じ色の **3つ目** を置いたら、その色は右へ1マス上がります。4つ目以降は上がりません［2］。

## 相場変動

株の購入トラックか金の購入トラックが埋まる（5マス、5席は6マス）、または今の売却トラックの残りが5つ（5席は4つ）になると起こり、終わったら手番の続きをします［1］。

1. 袋から、レベルの数だけ株を引きます。
2. **金価格**：引いた黒1つにつき1マス、前の相場変動から買われた延べ棒3本ごとに1マス上げ、金の購入数を0に戻します。$100 より上へは進みません［1］。
3. **株価**：紫 → 黄 → 緑 → 青 → 白 の順に、色ごとに引いた数で動かします［1］。
   - 黒がちょうど1つ：袋に戻します（引き直しなし）。数はそのまま。
   - 黒が2つ以上：各色の数から黒の数を引きます（マイナスにもなる）。黒は銀行へ。
   - 数 n の動き：n ≥ 1 なら上へ ⌈n/2⌉ 行、n が偶数ならさらに右へ1マス。n = 0 なら左へ1マス。n ≤ −1 なら下へ ⌈|n|/2⌉ 行、|n| が偶数ならさらに左へ1マス。（盤面の早見表：+1 上、+2 上右、+3 上上、…、0 左、−1 下、−2 下左、…）
4. **片づけ**：引いた色の株は市場へ。変動を起こしたトラックの株を袋へ（売却トラックなら横の黒も）［1］。
5. 市場に1株もない色は **上へ1マス**［1］［2］。
6. **レベル**：いちばん高い色のいる区画が、まだ黒の残っている新しい区画なら、そのレベルになります。新しいレベルと飛ばしたレベルの黒を袋へ。レベルは下がりません［1］。
7. **売却トラック**：上の段で変動が起きたら次は中段、中段なら下の段。下の段で変動が起きたら、最後に中段へ市場から各色2株と銀行の黒2つを補充し、以後は中段だけを使います。足りない分は空けておきます［1］［2］。

## ボーナスタイル（1回だけ）

- 2. は利点1だけ、3. は1と2、4. は1〜3、5. は1〜4のどれか1つを、ゲーム中に1回だけ使えます。使ったら箱へ［2］。
  1. アクションとは別に「0株買う」「0株売る」「0本の金を買う」をする（市場から1株を購入トラックへ置く、または売却トラックから1株外して市場へ戻す）。アクションの前に使えば、それで相場変動を起こしてからアクションができます［2］。
  2. 売るとき上限より1株多く。
  3. 金を買うとき上限より1本多く。
  4. 買うとき上限より1株多く。

## M.I.B.S.（2人では必ず、3〜4人では選べる、5人では入らない）

ついたてを使わず、お金と株はいつも公開。袋から5株と $100 で始め、いつもスタートプレイヤーです［1］［2］。

- 上限いっぱいに買えるお金があれば買います。買い方は「いちばん安い株を上限まで（足りなければ次に安い色）」と「金を上限まで」の合計金額をくらべ、株が同じか安ければ株、そうでなければ金［1］。
- 株を買うとき：安い色から。同じ値段なら **自分の持っている株が少ない色**、それも同じなら 紫 → 黄 → 緑 → 青 → 白［2］。
- 購入トラックに置く株：株を買ったときは買った色から、金のときはどの色からでも、**自分がいちばん多く持っている色**。同数なら高い色、同じ値段なら市場の株が少ない色、それも同じなら色の順。持っている色が市場になければ、いちばん安い色（同じなら市場の株が多い色、次に色の順）［1］［2］。
- 上限いっぱいに買えないときは売ります：上限まで、高い色から（同じ値段なら多く持っている色、次に色の順）。持ち株が上限より少なければ全部［1］［2］。
- 売却トラックから外す株：売った色のうち **自分の持っている株がいちばん少ない色**。同数なら安い色、同じ値段なら市場の株が多い色、次に色の順。売った色がトラックになければ、いちばん高い色（同じなら市場の株が少ない色、次に色の順）［1］［2］。
- 株を持っていなくて上限まで買えないときは、安いほうを買えるだけ買います。それもできなければ、いちばん安い色（同じなら市場の株が多い色、次に色の順）を1株、金の購入トラックへ置きます［1］。
- 終了時はほかの人と同じく清算し、M.I.B.S. がいちばんならプレイヤーは全員負けです［1］。

## ゲームの終わり

- 金価格が $100 に届いた相場変動を最後まで行ってから、ゲームは終わります（「Die Partie endet nach der Kursänderung, durch die ihr den Goldmarker … auf das Feld 100 versetzt.」）［2］。
- 手元の株を今の株価で売ります（この売りでは株価は動きません）。延べ棒は1本 $100［1］。
- お金がいちばん多い人の勝ち。同点なら金（延べ棒）を多く持っている人［1］。

## ルールに書かれていないため決めた所

1. **中段の売却トラックの補充をくり返すか**：ルールは「下の段で相場変動を起こしたら中段を補充する」「下の段のあとは中段だけを使う」とだけ書いています［1］［2］。中段だけを使い続けるには補充が要るので、このブラウザ版は **中段で相場変動が起きるたびに中段を補充** します（補充しないと、中段が空になったあと売りで株価が下がらなくなり、銀行にたまった黒が袋に戻らなくなります）。
2. **いちばん高い色が2つの区画にまたがって同じ値段のとき**（例：$150 は区画8と区画7にあります）：高いほうの区画でレベルを判定します。
3. **ボーナスの利点1をアクションのあとに使えるか**：ルールは「アクションの前に使えば相場変動を起こせる」と書いており［2］、利点はアクションとは別に使えるので、アクションのあとにも使えるようにしています。
4. **相場変動の早見表で行と列の両方に動くとき**：上下を先、左右をあとに1マスずつ動かして見せます（盤の端の折り返しを含めて、行き先はどちらの順でも同じです）。
5. **M.I.B.S. のボーナスタイル**：M.I.B.S. はいつもスタートプレイヤーなので、持ちません［2］。

## このブラウザ版だけの表示と補助

- ほかの人の現金と金の本数：支払いはすべて公開なので、計算して表示します（設定で隠せます）。最初に引いた5株の色は本人と M.I.B.S. 以外には見えません。売った数が買った数より多いと「少なくともその色を持っていた」ことがわかるので、その分は表示します。
- 袋の中：全体の数と黒の数は数えればわかるので表示します。色ごとの数は、場に出た株・トラックから入った株・公開の取引から計算した見込みです。次の相場変動で黒が2つ以上出る確率も表示します（設定で隠せます）。
- CPU は4段階。「つよい」「最強」は、見えない手札と袋の中身をいくつも想像し、本物のエンジンで先までためしてから動きます。CPU も見えないはずの情報は使いません。

## テスト

- `node tools/blackfriday-rules-test.mjs`：盤面データ、動き方、準備（全人数・M.I.B.S.）、売買と金、ルールブックの例、相場変動（5席・早見表・レベル飛ばし）、売却トラックの補充、ボーナスタイル、終了と同点、見える情報、M.I.B.S.、300ゲームの数の保存。
- `node tools/blackfriday-selfplay.mjs 200 1 2 3 4`：CPU どうしの対戦。
- `node tools/blackfriday-browser-check.mjs`：Chromium で、スマホのCPU戦・続きから・1台でみんなで・PCの5席CPU戦・オンライン2タブ（途中で再読み込み）を、ボタンを押して最後まで遊びます。
- `node tools/blackfriday-cover.mjs`：箱絵（`games/img/black-friday*.webp`）と共有画像（`og.jpg`）を three.js で描きます。
