# エレメンティカ（アプリ版）のルールと数値

ボードゲーム「エレメンティカ」（14games、2026年）を、CPU対戦とオンライン対戦で遊べるようにした非公式版です。
ルールの流れは英語版ルールブックに沿っています。チップ・プラント・マップ・トラックに印刷された数値は公開資料から読み取れなかったため、下の値はこのアプリで決めたものです（`engine.js` の先頭にまとめてあります）。本物の数値がわかったら、そこを書き換えれば合わせられます。

## 流れ

- 2〜4人。全員コイン6・労働力1・白い計画書チップ3枚（拠点／建設／コイン+2）で始める。
- 準備ラウンド：手番の逆順に拠点を1つずつ置く（2コイン＋隣の相手の拠点1つにつき1コインをその人へ）。
- 1ラウンド：アクション（1人2回、第1ラウンドだけ1回）→ 魔力生産 → 収入 → 給料 → 手番順の更新（最終ラウンドはなし）。
- 誰かが15VP以上でラウンドを終えると次が最終ラウンド。その給料の後に最終得点。14ラウンドで打ち切り（安全のため）。

## アクション

1. 手元の計画書チップを0〜3枚、3つのマスに置く（表か裏）。
2. ちょうど3枚なら、色の並び（左→右）が自分の魔力プラントエリアの埋まった行と一致した行の行ボーナスを得る（虹は1枚だけどの色にも、2枚以上は不成立。白は一致しない。アーティファクトはその2色のどちらでも）。
3. 左から実行。チップはその面の効果、空きマスは印刷の効果：左「研究+1」、中「拠点を置く」、右「プラント建設」。使わないこともできる。
4. 置いたチップは捨て場へ。アクションの前か後に手元が空なら、捨て場のチップを全部手元へ。

## 省いたもの

- 公式のソロモード（オートマとシナリオカード）。かわりにCPU相手に遊ぶ。
- 給料フェイズ中のフリーアクション（自分の手番と魔力生産のときは使える）。
