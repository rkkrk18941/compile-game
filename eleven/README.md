# Eleven / イレブン

非公式のブラウザ版。ゲームデザイン：佐藤雄介、原作：新ボードゲーム党／ケンビル。イラストはブラウザ版独自のSVG・CSSで、製品画像は同梱していません。

## 遊び方と対応範囲

- CPU対戦：人間1人＋CPU1〜5人。やさしい／ふつう。
- 端末を交代する2〜6人対戦。手札を隠してから次の人に渡す方式。
- 数字・色順の整列、手のヒント、任意の効果音、履歴、端末内の中断保存と再開。
- 基本ルールを実装。オンライン対戦と「多色ってきれい」ヴァリアントは未実装。

100枚：5色×1〜9×各2枚と、無色の10/0が10枚。2枚以上の連番を出すと色の種類だけ補充。無色は色数に含めず、0か10として連番の端に使用。1枚捨てて山札／他人の場札から補充するか、交換札と入れ替えることも可能。古い自分の場札は、新しい連番を出すときだけ捨てる。

手札全部を1色の連番として出すと得点。残り1枚でも可。山札でめくった数字が得点となり、同じ枚数を補充する。得点の1は加算してもう1枚めくり、補充には最後の数字を使う。得点の10/0は10点。合計11点以上に達すると即勝利。山札切れでは捨て札だけを混ぜ直す。

## 構成と検証

依存なしの静的HTML/CSS/ES Modules。GitHub Pagesで `/eleven/` を公開し、既存の `/games/` に追加。

```sh
node --test eleven/engine.test.mjs
node --check eleven/game.mjs
```

ルール・無効入力の非破壊性・シャッフル・CPUの非透視を検証。シードを固定した40試合（2〜6人、各8試合）で決着と全100枚の保存を毎手確認。CPUは自分の手札、公開場札、交換札だけを判断に使用する。
