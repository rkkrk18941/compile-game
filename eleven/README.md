# Eleven / イレブン

ボードゲーム『イレブン』（ゲームデザイン：佐藤雄介、原作：新ボードゲーム党／ケンビル）のルールで遊べる、非公式のブラウザ版。製品版の画像は使っていません。カードの宝石・数字・裏面はすべてこのページ用に描いたオリジナルのSVG／CSSです。

## 遊び方と対応範囲

- CPU対戦：あなた＋CPU1〜5人（ジェイド、オパール、ガーネット、アンバー、オニキス）。やさしい／ふつう。
- みんなで対戦：1台を回して2〜6人。手番ごとに「手札を見る」画面をはさみ、ほかの人の手札は見えません。名前を付けられます。
- 数字順・色順の並べ替え、ヒント、効果音（WebAudioで合成、ON/OFF）、プレイ履歴、端末内の自動保存と「続きから」。
- 基本ルールを実装。オンライン対戦と「多色ってきれい」ヴァリアントは未実装。

100枚：5色（青サファイア・緑エメラルド・紫アメジスト・橙トパーズ・赤ルビー）×1〜9×各2枚と、無色の10/0（ダイヤ）が10枚。色ごとに宝石の形（丸・八角形・三角・ひし形・ハート）が違うので、色が見分けにくくても形で判別できます。6と9は下線付き。

2枚以上の連番を出すと色の種類だけ補充。10/0は色数に含めず、0か10として連番の端に使用。1枚捨てて山札／他人の場札から補充するか、交換札と入れ替えることも可能。古い自分の場札は、新しい連番を出すときだけ捨てる。手札全部を1色の連番として出すと得点（残り1枚でも可）。山札でめくった数字が得点、得点の1は加算してもう1枚めくり、補充は最後の数字の枚数。10/0は10点。合計11点以上で即勝利。山札切れでは捨て札だけを混ぜ直す。

## 画面

テーブルの見た目と操作は PLAYROOM のスカルキングに合わせています（夜の背景、金の見出し、上に相手のプレート、中央にテーブル、下に扇状の手札、下から出るシート）。

- 上：相手ごとのプレート（名前・手札枚数・11マスの得点ゲージ・場札）。手番の人は金枠。
- 中央：山札／交換札／捨て札と、直前の手（出した連番、捨てた札→取った札）。
- 下：あなたの点数と場札、操作ボタン、手札。1枚選ぶと、山札・交換札・相手の場札が光って取れる場所を示します。
- 動き：カードは実際に移動した場所へ飛びます（手札→場札、山札→手札、CPUの手札→場札）。4枚以上の連番や出し切りはスタンプ、得点はカードをめくる演出、勝者は結果画面。
- 縦持ち・横持ち・PCに対応。背の低い画面では中央の表示を自動で詰めます。

## 構成と検証

依存なしの静的HTML/CSS/ES Modules。`engine.mjs`（ルールとCPU、画面から独立）／`game.mjs`（テーブルUI）／`style.css`／`index.html`（宝石のSVGシンボル）。GitHub Pagesで `/eleven/` を公開し、`/games/` に掲載。保存キー `playroom.eleven.v1` は前の版と共通で、中断中のゲームはそのまま続きから遊べます。

```sh
node --test eleven/engine.test.mjs
node --check eleven/game.mjs
```

ルール・無効入力の非破壊性・シャッフル・CPUの非透視を検証。シードを固定した40試合（2〜6人、各8試合）で決着と全100枚の保存を毎手確認。CPUは自分の手札、公開場札、交換札だけを判断に使用する。`?test=1` を付けると演出を省いて高速に進みます（自動テスト用）。
