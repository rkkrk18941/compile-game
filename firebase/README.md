# オンライン募集掲示板の共有設定

対象: `compile-game-online` の Realtime Database。

ゲームの部屋 (`rooms`) と募集一覧 (`matchmaking`) は別のデータです。
現在の部屋用のルールを維持し、募集一覧だけを追加してください。

1. Firebase Console → `compile-game-online` → Realtime Database → ルールを開く。
2. 現在のルールをコピーして保存し、戻せるようにする。
3. `matchmaking.rules.fragment.json` の `matchmaking` ブロックを、既存の `rules` オブジェクト直下へ追加する。既存の `rooms` ブロックと同じ階層です。
4. 公開を押し、ゲームを再読み込みして、ホームの「オンライン対戦」を開く。

**このファイル全体で現在のルールを置き換えないでください。** 既存の通信ルールが消えるためです。
`rules` 内の既存の項目の末尾にカンマを付け、次の項目として `matchmaking` を追加します。

募集には名前・タイトル・カードセット・CONTROL設定・部屋コードだけを保存します。
匿名認証したプレイヤーが最大100件の一覧を読めます。募集を作成・変更・取り消せるのは作成者だけです。
手札・デッキ・ゲーム中の通信は募集一覧に保存しません。
募集は20秒ごとに更新され、接続が切れた場合に取り消します。古い募集は2分で一覧から消えます。

確認手順: 2台で同じゲームURLを開き、1台が名前と募集タイトルを入力して募集し、もう1台が一覧から参加します。
両端末で同じ2人の名前が表示されたら、ホストがドラフトを開始してください。
募集は参加者が決まった時点で一覧から消えます。3台目が同じ部屋に同時参加しても、部屋の参加権はトランザクションで1人に限定します。

戻す場合: 保存した元のルールを再公開します。ゲーム側は招待コードによる参加を引き続き使用できます。
