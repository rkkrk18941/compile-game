# AIトレーダー（デモ）

本物の株価（日足）と仮想のお金300万円で、日本株を自動売買するデモです。
ページ：https://rkkrk18941.github.io/compile-game/games/ai-trader/

## しくみ（4ステップ）

1. **戦略を探す**（`bot/strategies.py`, `bot/search.py`）
   11個の作戦（ゴールデンクロス・高値ブレイク・押し目買い・ボリンジャー逆張り・強い銘柄に乗る）を、
   直近3年の株価で試し、シャープレシオが一番高いものを採用。取引10回未満・成績マイナスの作戦は使わない。
   いまの作戦より明らかに良い（シャープ+0.1以上）ときだけ乗り換え。週1回やり直す。
2. **バックテスト**（`bot/search.py`）
   「毎年1月に、その前の3年だけで作戦を選び、その1年を運用」を2019年から繰り返す（ウォークフォワード）。
   後から一番良かった作戦を選ぶ答え合わせではないので、本番に近い成績が出る。
3. **リスク管理**（`bot/engine.py`）
   1回の損失は資金の1%まで・逆指値（ATRの2.5倍下）・利益が出たら逆指値を引き上げ（最高値−ATR×3）・
   最大5銘柄・1銘柄25%まで・口座が最高値から15%減ったら10営業日は新規の買いを停止。100株単位。
4. **自動で売買**（`bot/engine.py` の `step()`）
   終値でサインを判定 → 次の営業日の寄付き（始値）で約定。バックテストもデモ口座も同じ `step()` で動く。

## 自動実行

`.github/workflows/ai-trader.yml` が平日 17:17（日本時間）に動き、結果を `data/` にコミットする。
GitHub の「Actions」タブ →「AIトレーダー（デモ）」→「Run workflow」で手動実行もできる
（「戦略探しを今すぐやり直す」にチェックで、戦略探しもやり直す）。

- 大引け前（16時より前）に動いた場合、その日の足は使わない（途中の値段で判断しないため）。
- 同じ日に何度動いても、新しい営業日がなければ何も変わらない。
- 株価は Yahoo!ファイナンス（yfinance）。取れないときは Stooq。株式分割は調整済み、配当は含めない。

## 設定を変える

`config.json`：仮想資金、リスク管理の数字、売買コスト、銘柄リスト。
※ デモ口座の状態は `data/state.json`。これを消すと、次の実行で口座が最初からやり直しになる。

## 手元で試す（本物のデータは使わない）

```
cd games/ai-trader
python3 tests/test_bot.py      # 約定・逆指値・ブレーキ・日次実行のテスト（作りものの株価）
```

## 注意

これは仮想のお金で動くデモです。特定の銘柄の売買をすすめるものではありません。
過去の成績は、将来の成績を保証しません。
