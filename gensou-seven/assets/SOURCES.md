# Image sources

Card illustrations and card design: Fantasy Realms original English base edition, © WizKids / NECA LLC. Original author: Bruce Glassco. This is an unofficial fan-made browser implementation.

- Product: https://wizkids.com/fantasy-realms/
- Card scans (53 cards and back): https://github.com/krzysztof-kozak/fantasy-realms/tree/master/public/deck
- Parchment background and logo: https://github.com/fantasy-realms/fantasy-realms.github.io/tree/gh-pages/img

The original images are preserved. The original illustration region is retained. Japanese names, suits and effect explanations are typeset inside the card using HTML; the original English effect region is not displayed. No claim of official endorsement is made.
