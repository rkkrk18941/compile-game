# Hatatori card emblems

`gilded-emblems-v1.webp` and `graphic-emblems-v1.webp` are original AI-generated transparent emblem atlases for the two optional card designs. The existing silhouette deck remains available.

Each sheet contains the ten troops, nine tactics motifs and a common back emblem. `card-skins.js` maps the five columns and four illustrated rows; native canvas typography, suit indices and card frames are drawn separately so they stay readable and accurate in all six colors. Artwork is also reused by the formation effects. The chosen effect theme is independent of the chosen deck.

Generation: built-in Image Gen, transparent background. Prompt: a five-column/four-row atlas of centered symbolic military emblems (sling, bow, javelin, hoplite, pikes, guard, two cavalry types, chariot, elephant; commander, cavalry crest, shield, fog, mud, scout, redeployment, desertion, betrayal; flag medallion). A uses antique-gold heraldic engraving; B uses bold black/ivory geometric silhouettes. No text, numbers or card frames are part of the generated artwork.
