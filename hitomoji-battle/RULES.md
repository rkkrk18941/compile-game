# ヒトモジ・バトル（あいうえバトルのルール）仕様

ブラウザ版 `hitomoji-battle/` が実装しているルールと、その根拠です。
資料の確認日は 2026-10-17 です。各項目の［ ］は下の「出典」の番号です。

## 対象と版

- 原作はボードゲーム『あいうえバトル』です。ゲームデザインは米光一成です［1］［2］［4］。
- 版は3つあります。
  - **紙とペンの無料版（2020年）**：コロナ禍に、ビデオ通話でも遊べるゲームとして公開されました。アークライトの「遠隔ボドゲ」で、ルールPDFと用紙PDFが配られています（2〜6人、10歳以上、約15分）［3］［4］。
  - **Anaguma版（第二版、2021年）**：2〜6人、10歳以上、15分〜。ちょっかんくん6種×7体、ちょっかんチップ47枚（木製）、あいうえボード（両面）、ホワイトボードマーカー6本。アートワークはクボナオ［2］［11］。
  - **幻冬舎eduの新版『もじあてゲーム あいうえバトル』（2024年3月30日発売）**：Anaguma版をコンパクトにした新版で、2〜5人、6歳以上、約15分。ちょっかんくん40枚（各色1枚予備）、ボード1枚（両面）、ホワイトボードマーカー5本、2,310円。日本ボードゲーム大賞2024投票部門の大賞［1］［5］［8］。新版では、チップの代わりにボードの文字へマーカーで斜線を引きます［6］［16］。
- このブラウザ版は、3つの版に共通するルールで作り、細かい点は新版の説明に合わせています。人数はAnaguma版の上限に合わせて2〜6人です。
- 公式名は「あいうえバトル」です（「あいうえおバトル」ではありません）。

## 言葉の書き方

- お題を決め、各自がお題に合う **2〜7文字** の言葉を考えます［1］［6］［7］［9］。
- ちょっかんくん（このアプリでは「ふだ」）7枚に、1枚1文字ずつ書きます。他の人に見えないように立てて並べます［1］［7］。
- **ひらがな** で書きます。**濁点（゛）と半濁点（゜）は書きません**。**小さい文字（っ ゃ ゅ ょ）は大きく書きます**［1］［6］［7］［9］。
  - 例：スパゲッティ → す は け つ て い ×［11］、ジャム → し や む、パン → は ん［12］、レモネード → れ も ね ー と ×× ［15］
- **長音「ー」は1文字** として書きます。ボードにも「ー」があり、攻撃できます（プレイ例で「ー」を宣言している［7］、「あ〜ん（もしくは横棒）」［11］、チップ47枚［2］、「長音を含めて47文字」［13］）。
- 6文字以下のときは、余ったふだに **×** を書きます。×は攻撃されません［1］［6］［7］。
- 並べ方：自分から見て右から左へ読めるように置きます（相手からは左から右に読める）［6］［7］［10］。

## ボード（あいうえボード）

- 表面は五十音、裏面はアルファベットです［1］［2］［7］。
- 文字は **47字**：あ〜ん（を・んを含む46字）と「ー」です。チップが47枚であること［2］、「47音」［14］、「長音を含めて47文字」［13］から、この並びと判断しました（未確認事項1）。
- 宣言した文字には、チップを置く（Anaguma版）か斜線を引き（新版）、もう使えません［1］［6］［7］。

## 手番

1. 手番の人は、ボードの文字を1つ宣言して「攻撃」します［1］［6］［7］。
2. その文字が書かれたふだを持つ人は、**その文字のふだを全部** 開いて見せます。同じ文字が2枚あれば2枚とも開きます［6］［10］。
3. **宣言した本人の言葉にその文字があれば、本人のふだも開きます（自爆）**［3］［8］［10］。
4. **1枚でもふだが開いたら、もう1回だけ** 続けて宣言できます。1回の手番で宣言できるのは **最大2回** です［1］［6］［7］［10］［11］。
5. 何も開かなければ（はずれ）、または2回宣言したら、手番は左隣（時計回り）の人に移ります［7］［8］。
- 相手の言葉がわかっても、口で答えを言ってはいけません。かならず1文字ずつ攻撃します［8］。
- 最初の手番の人は任意の方法で決めます［6］［14］。説明書の例では、お題を決めた人から始めます［12］。

## 脱落と勝敗

- **×以外のふだが全部開いた人は脱落** です［1］［6］［7］。脱落した人は×のふだも開いて見せ［12］、以後は攻撃しません［10］。
- **最後まで残った1人の勝ち** です［1］［6］［7］。
- **最後に残った人たちが、同じ宣言で同時に脱落したときは、宣言した人の勝ち** です。無料版のルールでは「最後の残り2人が同時にライフ0になった場合は、攻撃した側が自爆を避けて生き残る」［3］。新版の解説でも「最後に攻撃を成功させた（自爆した）プレイヤーの勝ち。引き分けはない」［10］、「同時に脱落した場合は手番プレイヤーの勝ち」［9］。
- 得点や複数ラウンドのルールはありません（勝ち残りだけ）［6］［7］。

## ブラウザ版での扱い

### 書くこと・判定すること

- 言葉はキーボードで入れます。カタカナ・半角カナで入れても、ひらがなに直し、゛゜を取り、小さい字を大きくして、ふだに書いた形をその場で見せます（例：ジャガー → しやかー）。ヴはう、ヵヶはかけ、ゐゑはいえに直します。「・」や空白は消し、キーボードの「-」「〜」は「ー」として扱います。
- 漢字は読みがわからないので使えません（ひらがなかカタカナで入れます）。「文字ボタン」でボードの文字を押して書くこともできます。「おまかせ」は、そのお題のことばリストから1つ選びます。
- ふだが開くかどうか、脱落したかどうかはアプリが自動で判定します。
- 結果では、各自が入力したとおりの言葉（例：ジャガー）と、ふだに書いた形（しやかー×××）の両方を見せます。
- ボードの青い線は、あなたの言葉にまだ隠れている文字の印です（設定で消せます）。実物では自分で覚えておくことなので、補助の表示です。印のある文字をえらぶと、自爆の注意が出ます。
- えらんだ文字をもう一度タップするか、「攻撃する」で宣言します。

### お題

- 説明書のお題一覧は使わず、このアプリ用に作ったお題を使います：日本語32種（どうぶつ、くだもの、やさい、のみもの、たべもの、おかし、スポーツ、がっき、ぶんぼうぐ、がっこうにあるもの、だいどころにあるもの、のりもの、しょくぎょう、くにのなまえ、とどうふけん、うみのいきもの、むし、とり、はな、からだのぶぶん、かぐ・かでん、ふく・みにつけるもの、なつといえば、ふゆといえば、まちのたてもの、いろ、あそび・おもちゃ、どうぐ、てんき・そら、せかいのとし、あかいもの、いきたいところ）、英語20種。
- 「おまかせ」は毎回ちがうお題をランダムに選びます。「なんでも」はお題なしで好きな言葉を書くモードです。
- オンラインでは、ホストが「じぶんで決める」で自由なお題を書けます（CPUはお題を理解できないので、CPUがいないときだけ）。
- ことばリストはCPUが自分の言葉を選び、相手の言葉を推理するために使います。リストにない言葉を書いても、もちろん遊べます。

### 追加の設定（原作にない遊び方）

- **言葉の長さ「2〜5文字（短め）」**：小さい子どもや初めての人向けに、文字数を減らす遊び方です（文字数を変えるハウスルールの紹介［17］による）。初期設定は原作どおり2〜7文字です。
- **アルファベット**：ボード裏面の英語で遊ぶモードです。A〜Zの26字、2〜7文字の英単語。

### 順番と順位

- 1回めの最初の人はランダムに決め、「もう一度」のたびに次の人へずらします。
- 結果の順位は、勝った人が1位、あとは脱落が遅かった順です。同じ宣言で同時に脱落した人は同じ順位です。棄権した人は最後です。

### CPU

- CPUは、テーブルに見えていること（開いたふだ、宣言された文字、お題）と自分の言葉だけで考えます。ほかの人の言葉はのぞきません。
- 相手ごとに、ことばリストの中から「開いたふだ」と「まだ開いていない場所に、宣言ずみの文字はない」に合う言葉を数え、どの文字なら何枚開きそうか、脱落させられそうかを見積もります。リストにない言葉に備えて、文字の出やすさも混ぜます。
- 自分の言葉にある文字（自爆）は、開く枚数と残りの枚数に応じて避けます。最後の文字で全員を同時に脱落させられるときは、わざと言います（宣言した人の勝ちになるため）。
- 強さ：**やさしい**（文字の出やすさだけで選び、ときどき自爆に無頓着）、**ふつう**（お題のことばリストで推理）、**つよい**（リスト外の言葉も少し考え、候補をよく分ける文字を選び、読まれにくい言葉を書く）。
- 回帰テストの自己対戦（2人、各120戦）では、つよい対やさしいで約100%、つよい対ふつうで約60%、ふつう対やさしいで約98%勝ちます。

### オンラインでの扱い

- 部屋コード（4文字）でつなぎます。通信は PeerJS（WebRTC）で、ホストのブラウザがテーブルを管理します（PLAYROOM のほかのゲームと同じ方式）。
- **言葉はそれぞれの端末から出ません。** 書いたとき、その端末から送るのは「ゲーム番号・席・7枚のふだ・ランダムな塩」の SHA-256 ハッシュ（約束）だけです。ホストのブラウザにも言葉は届きません。
- 宣言のたびに、各自の端末が自分のふだを見て「開く場所」と「脱落したかどうか」だけを答えます。脱落したときと、ゲームの終わりに、言葉と塩を公開します。
- 公開された言葉は、全員の画面で「最初の約束と同じか」「これまでのすべての答えと合っているか」を照合し、結果画面に表示します（engine.js の `checkWord`）。答えをごまかすと、ここで「一致しません」と出ます。
- 言葉と塩は、そのタブの sessionStorage に保存します。ゲスト（ホスト以外の人）がページを再読み込みしても、同じコードで入り直せば同じ席で続けられます。
- ゲストの接続が切れると、ホストの画面に表示が出ます。10秒たっても戻らないときは、ホストが「棄権にする」でその人を脱落扱いにして進められます（その人の言葉は不明のまま）。
- ホストのページを閉じると、その対戦はおわります。
- CPUはホストのブラウザで動きます。

## 未確認事項

この環境からは、次の資料を直接確認できませんでした。

- 新版（幻冬舎edu）の説明書の原文：Webで本文を読めませんでした。新版のルールは、公式ページの概要［1］と、新版を遊んだ人の解説［8］［10］［12］［15］によります。
- 無料版のルールPDF［3］：文章の要約は確認できましたが、画像の細部は確認できていません。

完全に確定させるには、次の点を説明書で確認する必要があります。

1. **ボードの文字の並び**：「を」と「ー」の位置。このアプリは五十音表の形（右から あ・か・さ…わ、左端に ん と ー）で並べています。47字という数から「を」も含まれると判断しています。
2. **自爆だけで連続攻撃できるか**：新版の説明書の文言。資料の多くは「できる」としています（設定で切り替え可能）。
3. **3人以上が同時に全員脱落したとき**：資料は「最後の2人」の例だけです。このアプリは「宣言した人の勝ち」に統一しています。
4. **脱落したときに×のふだも見せるか**：［12］の記述によります。
