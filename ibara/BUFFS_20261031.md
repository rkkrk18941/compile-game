# キャラクター強化（ハウスルール）と自動プレイでの確認（2026-10-31）

依頼：「アイアンクラッド・サイレント・ウォッチャーを強化。設定で通常に戻せるように（初期設定は強化あり）。自動プレイAIで勝率などがおかしくないか確認」。

## ルール（`bg/data.js` の `D.BUFFS`）

| キャラ | 強化内容 |
|---|---|
| アイアンクラッド | ターン終了時：HPを1回復。その時HPが1なら、さらに1回復（合計2）。 |
| サイレント | ターン開始時：毒を持っていない敵1体に毒1を与えられる（候補が1体なら自動、複数ならタップで選択・「使わない」も可）。ターン終了時（毒のダメージの後）：敵の毒をすべて取り除き、取り除いた数だけブロックを得てもよい（毎ターン選択。毒を残すこともできる）。 |
| ウォッチャー | スタンスを変えるたび（スタンス解除を含む）ブロック1。 |

ディフェクトと拡張キャラクターは変わりません。サイレントの「変換するか毎ターン選べる」はユーザーに確認済み。

処理の位置（`bg/combat.js`）：アイアンクラッドの回復とサイレントの変換は、ターン終了時の「防御などの効果」の段階（毒・ライトニングのダメージの後、火傷・憤怒などの被ダメージの前）。サイレントの毒1はターン開始時の最初（有毒ガスなどより前なので、毒のない敵を自由に選べる）。ブロックが上限20の時は変換の質問を出さない。

## 設定

- 設定画面（タイトル右上・冒険中のメニュー）の「キャラクター強化：強化あり／通常（強化なし）」。ひとりで遊ぶの「追加設定」とオンラインの部屋（ホスト）にも同じ切り替え。端末に保存（`ibara.bg.prefs.v1` の `heroBuff`、初期値は強化あり）。
- 冒険ごとの状態は `run.buff`（エンジンの初期値は通常＝印刷どおり）。1人プレイ・ホストは新しい冒険、続きからの冒険（この機能より前のセーブを含む）、遊んでいる途中の冒険のすべてに設定を反映。オンライン協力ではホストの設定が全員に使われ、参加者には「ホストの設定」と表示。
- 強化ありの冒険は上部に「強化」の札。キャラクター能力（レリック欄の先頭）、準備画面、用語集（「キャラクター強化」）に内容を表示。戦闘ログ・演出に「キャラ強化」と理由を表示。
- オンラインの通信バージョンを9に更新（古いページの参加者には再読み込みを案内）。

## 自動プレイでの確認

`node tools/ibara-buff-balance.cjs 1000` — `tools/ibara-bot.cjs`（ビーム探索の自動プレイ）で1人プレイの冒険（第1〜3幕・アセンションなし）を各キャラ1000回、同じシードで「通常」と「強化」を比較。サイレントの変換は、そのラウンドに受けるダメージを減らせて、毒を残すより得な時に選ぶ。

| キャラ | 第1幕ボス撃破 通常→強化 | 第3幕到達 通常→強化 | 冒険クリア 通常→強化 |
|---|---|---|---|
| アイアンクラッド | 33.4% → 69.8% | 0.8% → 11.3% | 0% → 1.7% |
| サイレント | 31.3% → 77.0% | 0.9% → 21.6% | 0% → 3.7% |
| ディフェクト（強化なし） | 39.8% → 39.8% | 1.4% → 1.4% | 0% → 0% |
| ウォッチャー | 8.9% → 22.1% | 0.0% → 0.2% | 0% → 0% |

（各1000回。95%区間はおおむね±3%。AIは人より弱く、通常ルールでは一度もクリアできないため、絶対値ではなく同じキャラの通常との差とキャラ間の順位を見る。）

勝った戦闘で失ったHP（第1幕 通常戦／エリート／ボス）：アイアンクラッド 1.26／3.06／4.96 → 0.61／1.79／3.01、サイレント 0.67／2.03／3.49 → 0.15／0.77／2.30、ウォッチャー 1.58／2.90／5.10 → 1.19／2.37／4.36。

2人協力（各組100回、`node tools/ibara-buff-balance.cjs 100 RG,GW,WR,RB,GB,BW 1`）の第1幕ボス撃破：アイアン＋サイレント 10%→53%、サイレント＋ディフェクト 6%→21%、アイアン＋ディフェクト 3%→16%、ウォッチャー＋アイアン 2%→8%、サイレント＋ウォッチャー 2%→5%、ディフェクト＋ウォッチャー 3%→1%（100回なので±数%の誤差）。

### 分かったこと

- 不具合・異常値なし：8000回でエラー0。通常ルールの結果は変更前の同じ1000シード×4キャラと完全に一致し、ディフェクトは強化オン／オフで完全に同じ（ほかへの影響なし）。
- 強化は3キャラとも大きく効く。順位は「通常：ディフェクト＞アイアン≒サイレント＞ウォッチャー」から「強化：サイレント＞アイアン＞ディフェクト＞ウォッチャー」に変わる。
- サイレントの伸びが最大（第3幕到達が約24倍）。持ち越した毒を複数の敵に広げてから、必要な時にまとめてブロックに変えられるため、第1幕の通常戦ではほぼ無傷（勝った戦闘の被ダメ0.15）。
- ウォッチャーは強化しても最下位（AIのスタンス運用が下手なことも影響）。
- アイアンクラッドで「戦闘が終わらない」膠着が1000回中2回（AIがアタックをすべて廃棄し、敵の攻撃は毎ターンの回復で相殺）。通常ルールなら少しずつHPが減って決着がつく場面。人が遊んでも、攻撃手段を失うと同じことが起こりうる（その時は冒険をあきらめる操作で終える）。集計では100ラウンドを超えた戦闘を膠着として打ち切る。

## テスト

- `node tools/ibara-buff-test.cjs`（jsdomが必要）：各強化の処理・順序・上限・オフ時は通常どおり、設定の初期値と切り替え（新規・続きから・途中の冒険）、毒を与える敵の選択と「使わない」、変換の質問と被ダメ見込み、能力表示。
- 既存のスレイザスパイアのテスト・ブラウザ確認（Playwright）がすべて通ることを確認。
