# キャラクター強化（ハウスルール）と自動プレイでの確認（2026-10-31）

依頼：「アイアンクラッド・サイレント・ウォッチャーを強化。設定で通常に戻せるように（初期設定は強化あり）。自動プレイAIで勝率などがおかしくないか確認」。

## 毒の変換とカード操作の修正（同日追記）

サイレントの変換は毒ダメージの**前**に変更。毒を持つ敵から任意の1体〜全体を選び、確定時に選んだ敵の毒をすべて取り除いて、その合計だけブロックを得る（上限20）。選んだ敵には今回の毒ダメージが入らず、選ばなかった敵には従来どおり入る。「すべての毒を残す」も可能。致死量の毒が付いた敵でも、変換を選べる。同キャラの協力プレイでは順番に選び、先の変換で消費した毒を再利用できない。通信バージョン10。

手札の対象指定カードを選び、敵をタップするだけで使用できる。範囲カードはタップした敵の列が対象。「使う」ボタンからの従来の操作も使用可能。Xコストは敵タップの後に支払う値を選ぶ。

以下の旧仕様・勝率計測は変更前の記録であり、今回の仕様での勝率を示すものではない。

## 変更前のルール（`bg/data.js` の `D.BUFFS`）

| キャラ | 強化内容 |
|---|---|
| アイアンクラッド | ターン終了時：HPを1回復。その時HPが1なら、さらに1回復（合計2）。 |
| サイレント | ターン開始時：毒を持っていない敵1体に毒1を与えられる（候補が1体なら自動、複数ならタップで選択・「使わない」も可）。ターン終了時（毒のダメージの後）：敵の毒をすべて取り除き、取り除いた数だけブロックを得てもよい（毎ターン選択。毒を残すこともできる）。 |
| ウォッチャー | スタンスを変えるたび（スタンス解除を含む）ブロック1とチャージ1。ターン終了時（毒などと同じ「敵へのダメージ」の段階）、チャージと同じダメージを敵1体に1ヒットで与えて0に戻す（複数いれば対象を選ぶ）。 |

ディフェクトと拡張キャラクターは変わりません。サイレントの「変換するか毎ターン選べる」はユーザーに確認済み。

ウォッチャーのチャージ（2回目の依頼で「HP1の時」として追加、4回目の依頼でHPに関係なく毎回に変更）は「一撃として」の指定どおり1ヒット：筋力・憤怒（+1）・脱力・弱体化はふつうのヒットと同じく効き、弱体化はその後1減る。アタックのカードを使ったわけではないので、鋭い外殻やトゲなど「アタックを使ったら」の反応は起きない。チャージは主人公のトークン欄に「チャージN」と表示。

処理の位置（`bg/combat.js`）：アイアンクラッドの回復とサイレントの変換は、ターン終了時の「防御などの効果」の段階（毒・ライトニングのダメージの後、火傷・憤怒などの被ダメージの前）。サイレントの毒1はターン開始時の最初（有毒ガスなどより前なので、毒のない敵を自由に選べる）。ブロックが上限20の時は変換の質問を出さない。

## 設定と表示

- 設定画面（タイトル右上・冒険中のメニュー）の「キャラクター強化：強化あり／通常（強化なし）」だけで切り替える。端末に保存（`ibara.bg.prefs.v1` の `heroBuff`、初期値は強化あり）。
- 「強化あり」などの表示はほかの画面に出さない（ユーザーの指定）。強化の内容は能力欄（ひとりで遊ぶの「能力・初期デッキ」、冒険中のキャラクター能力）に、元の能力に続けて書く。戦闘中の質問やログは「〇〇の能力」として表示。
- 冒険ごとの状態は `run.buff`（エンジンの初期値は通常＝印刷どおり）。1人プレイ・ホストは新しい冒険、続きからの冒険（この機能より前のセーブを含む）、遊んでいる途中の冒険のすべてに設定を反映。オンライン協力ではホストの設定が全員に使われ、参加者は設定画面で「この冒険：強化あり／通常」を確認できる。
- オンラインの通信バージョンを9に更新（古いページの参加者には再読み込みを案内）。

## ボスの能力（同じ依頼の2点目）

- マップ上部の「ボス：〇〇　能力を見る」とマップのボス部屋をタップすると、その幕のボス戦に出る敵（ボス本体、ブロンズオーブや狂信者などの同時に出る敵、覚醒者の第2形態など後から現れる敵。アセンション13の第3幕は2体のボス）ごとに、能力・HP（この人数・難易度）・行動一覧を表示。冒険のコピーで戦闘を組み立てて調べるので、実際の冒険は変わらない。
- 戦闘中にボス（敵）をタップした時の説明は以前からあり。能力の説明がなかったヘクサゴースト・ブロンズオートマトン（とオーブ）・ドヌー・デカ・トーチヘッド・Downfallのアイアンクラッドに説明を追加。モードで行動が変わる敵（ガーディアン・チャンプなど）は、今の行動に加えて行動一覧も表示。
- Downfallのボスの行動表で「特殊」としか書かれていなかった効果（毒液・ダークオーブ召喚・バッファ・憤怒・炎の障壁・呪い・スレイヤー関連・ナイフの召喚と復活・オーブの復活）を、予告と同じ言葉で表示。

## 自動プレイでの確認

`node tools/ibara-buff-balance.cjs 1000` — `tools/ibara-bot.cjs`（ビーム探索の自動プレイ）で1人プレイの冒険（第1〜3幕・アセンションなし）を各キャラ1000回、同じシードで「通常」と「強化」を比較。サイレントの変換は、そのラウンドに受けるダメージを減らせて、毒を残すより得な時に選ぶ。

| キャラ | 第1幕ボス撃破 通常→強化 | 第3幕到達 通常→強化 | 冒険クリア 通常→強化 |
|---|---|---|---|
| アイアンクラッド | 33.4% → 69.8% | 0.8% → 11.3% | 0% → 1.7% |
| サイレント | 31.3% → 77.0% | 0.9% → 21.6% | 0% → 3.7% |
| ディフェクト（強化なし） | 39.8% → 39.8% | 1.4% → 1.4% | 0% → 0% |
| ウォッチャー | 8.9% → 22.1% | 0.0% → 0.2% | 0% → 0% |

（各1000回。95%区間はおおむね±3%。AIは人より弱く、通常ルールでは一度もクリアできないため、絶対値ではなく同じキャラの通常との差とキャラ間の順位を見る。）

勝った戦闘で失ったHP（第1幕 通常戦／エリート／ボス）：アイアンクラッド 1.26／3.06／4.96 → 0.61／1.79／3.01、サイレント 0.67／2.03／3.49 → 0.15／0.77／2.30、ウォッチャー 1.58／2.90／5.10 → 1.19／2.37／4.36。

2人協力（各組100回、`node tools/ibara-buff-balance.cjs 100 RG,GW,WR,RB,GB,BW 1`）の第1幕ボス撃破：アイアン＋サイレント 10%→53%、サイレント＋ディフェクト 6%→21%、アイアン＋ディフェクト 3%→16%、ウォッチャー＋アイアン 2%→8%、サイレント＋ウォッチャー 2%→5%、ディフェクト＋ウォッチャー 3%→1%（100回なので±数%の誤差）。

### ウォッチャーのチャージ（強化ありだけを再計測、各1000回）

`node tools/ibara-buff-balance.cjs 1000 W 2 --modes on`（アイアンクラッド・サイレント・ディフェクトはチャージ追加の前後で1000回すべて同じ結果）。チャージが付くHPの条件を変えて比べ、ユーザーの選択で「HPに関係なく」に決定。

| チャージの条件 | 第1幕ボス撃破 | 第3幕到達 | クリア |
|---|---|---|---|
| チャージなし（ブロック1のみ） | 22.1% | 0.2% | 0% |
| HP1の時 | 23.8% | 0.2% | 0% |
| HP2以下 | 25.7% | 0.2% | 0% |
| HP3以下 | 27.5% | 0.3% | 0% |
| HP4以下 | 29.4% | 0.2% | 0% |
| **HPに関係なく（採用）** | **43.8%** | **1.7%** | **0.1%** |

採用後の強化ありの順位：サイレント 77.0% ＞ アイアンクラッド 69.8% ＞ ウォッチャー 43.8% ＞ ディフェクト（強化なし）39.8%。膠着・エラーなし。チャージの獲得は戦闘ログと小さな表示だけにし、毎回の字幕は出さない（ターン終了時の発射だけ字幕）。

### 分かったこと

- 不具合・異常値なし：8000回でエラー0。通常ルールの結果は変更前の同じ1000シード×4キャラと完全に一致し、ディフェクトは強化オン／オフで完全に同じ（ほかへの影響なし）。
- 強化は3キャラとも大きく効く。順位は「通常：ディフェクト＞アイアン≒サイレント＞ウォッチャー」から「強化：サイレント＞アイアン＞ディフェクト＞ウォッチャー」に変わり、ウォッチャーのチャージ採用後は「サイレント＞アイアン＞ウォッチャー＞ディフェクト」。
- サイレントの伸びが最大（第3幕到達が約24倍）。持ち越した毒を複数の敵に広げてから、必要な時にまとめてブロックに変えられるため、第1幕の通常戦ではほぼ無傷（勝った戦闘の被ダメ0.15）。
- ウォッチャーはブロック1だけの強化では最下位のまま（AIのスタンス運用が下手なことも影響）。チャージをHPに関係なく付けてディフェクト並み（43.8%）になった（上の表）。
- アイアンクラッドで「戦闘が終わらない」膠着が1000回中2回（AIがアタックをすべて廃棄し、敵の攻撃は毎ターンの回復で相殺）。通常ルールなら少しずつHPが減って決着がつく場面。人が遊んでも、攻撃手段を失うと同じことが起こりうる（その時は冒険をあきらめる操作で終える）。集計では100ラウンドを超えた戦闘を膠着として打ち切る。
