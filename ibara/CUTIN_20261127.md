# 必殺技カットイン（2026-11-27）

依頼：Xで話題になっていたスレスパ2の「アニメーションMOD」（大技でアニメのカットインが入る）のような演出を、このアプリにも入れたい。

MODそのものはPC版スレスパ2の本体に組み込むプログラムと、MOD作者の絵・動きなので、このブラウザ版には入れられない。そこで同じ種類の演出を、このページで描いて足した。使った絵は、すでに戦闘で表示しているキャラクターの絵（`img/heroes`）だけ。

## 遊ぶ人から見て変わったこと

| 場面 | 変更 |
|---|---|
| カットインが入る時 | レアカードを使った時（アタック・スキル・パワー）。または、アタック1枚で敵1体に6以上のダメージ（ブロック前。同じ敵への複数ヒットは合計）を与える時。後者は1ラウンドに1回まで（プレイヤーごと）。レリック・パワー・オーブ・ポーション・毒によるダメージは数えない。 |
| 見た目 | 暗転と集中線 → キャラの色の斜めの帯が流れ込み、帯の中をスピード線が走る → キャラの絵が残像を残して飛び込む → カード名（英語名と「★ レア・アタック」などの札、または「大ダメージ」）が閃光と一緒に着地 → 帯が閉じて攻撃が当たる。 |
| キャラの色 | アイアンクラッド＝赤、サイレント＝緑、ディフェクト＝青、ウォッチャー＝紫、スライムボス＝黄緑、ガーディアン＝金、ヘクサゴースト＝桃紫、ハーミット＝橙。 |
| 決めの一撃 | カットインの後の命中（最大3ヒット）にキャラごとの追加演出。アイアンクラッドは十字の斬撃と火の粉、サイレントは三筋の斬撃、ディフェクトは稲妻、ウォッチャーは光の柱、スライムボスは粘液のしぶき、ガーディアンは破片、ヘクサゴーストは立ち上る炎、ハーミットは弾の軌跡。1発目は衝撃の輪・キャラの残像の突進・専用の音。レアのスキルとパワーは、帯が消えた後にキャラの周りに光の輪。 |
| 長さ | ふつうの速さで0.96秒（同じラウンドの2回目以降は短い版で0.52秒）。「戦闘演出：はやい／とてもはやい」に合わせて短くなる。**タップで即終了**。「なし」では出ない。 |
| 動きを減らす設定（OS） | 帯と文字が静かに出て消えるだけ（スピード線・集中線・残像・閃光なし）。 |
| オンライン協力 | 自分のカード：上と同じ。仲間のカード：仲間のキャラの上に小さな帯（「名前・レアカード」とカード名）が1.25秒。進行を止めず、タップも邪魔しない。 |
| 設定 | 「設定・BGM」の「音量・効果音・戦闘演出」と、戦闘中のメニューに「必殺技カットイン：オン／オフ」。初期値はオン。端末に保存。 |
| ふつうのカード | 今まで通り。ストライク・防御・強打などの待ち時間は変更前と同じ（テストで比較）。 |

ボット1人の通しプレイ（アイアンクラッド、1回の冒険）では、カットインは6回だった。

## 絵と音

- 絵：キャラクターの戦闘の絵（`img/heroes`、既存）だけ。帯・スピード線・集中線・文字・光はページで描く。新しい外部素材はなし（`ART_CREDITS.md`）。
- 音：`fx.js` のシンセサイザーで作る（`cutin`、`cutinhit`）。
