## 解釈して実装したところ（印刷面・ルールブックから一意に決まらない点）

| 項目 | 実装 | 影響 |
|---|---|---|
| スライムのカードの「プレイした時」のヒット（巨大スライム・けんかスライム） | ルールブック p.4「スライムのヒットはスライムボスの筋力・脱力や敵の弱体化の影響を受けない」をスライムのカードに印刷されたヒット全体に適用 | 筋力を上げたスライムボスでも、これらのカードのダメージは増えない |
| スライムの1レベルに複数のヒット | 1体を対象にまとめて与え、途中で倒れたら残りは失う（基本版の複数ヒットのカードと同じ） | ほぼなし |
| 進化スライム Lv6「筋力」 | このスライムに筋力1 | Lv6到達時のみ |
| 押し潰す準備 | ターン開始時、選んだ敵に（ヒットではない）ダメージ、その後捨て札へ | 筋力・弱体化は乗らない |
| 一斉にかかれ！ | スライム1体につき1ヒットとして与える（各ヒットに筋力が乗る） | 筋力があると大きくなる |
| 複製体（2枚以上） | 1枚につき「次のアタックを2回」を1回ずつ | 複数枚の場合のみ |
| 優位（ハーミット）を2回使う | 次のアタックが連射を2つ得る | 2枚使った時のみ |
| 追尾射撃「装填してもよい」 | カードの処理が終わった後に選ぶ（捨て札からチャンバーへ） | なし |
| ガーディアンのターン開始時のモードシフト | 毎ターン、続けるか切り替えるかを選ぶ画面を出す | 操作が1回増える |
| Downfallのボス候補 | 依頼の仕様どおり「今回の冒険で選ばれていない全キャラクター」から抽選（ルールブックは「Downfallのボスから無作為」） | 公式のボスカードがあるキャラは公式データ、ないキャラは設計（ボスのデータ取得後に確定） |
| マインドブルームの「第1幕のボスと戦う」 | Downfallの冒険でも基本版の第1幕ボス | イベントのみ |
