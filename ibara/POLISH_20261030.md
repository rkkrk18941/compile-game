## 確認した範囲

実際のChromium（日本語フォント）で、スマホ縦（390×844・375×667・360×740）、スマホ横（844×390・667×375）、PC（1280×800）を操作。
ソロ：アイアンクラッド・サイレント・ディフェクト・ウォッチャーで第1〜3幕・敗北／勝利まで、Downfall（スライムボス）で第3幕まで。

各画面の初回表示を自動で撮影して目視（ネオー、戦闘、報酬、マップ、イベント各種、商人、休憩所、宝箱、ボスレリック、幕間、結果画面）。

## 直したこと

| 種類 | 内容 |
|---|---|
| 不具合 | 報酬画面の「先へ進む」で、受け取っていないゴールドやカード報酬が確認なしに消えていた。→ゴールドは自動で受け取り、それ以外が残っていれば「受け取らずに進む／戻る」を確認。 |
| 不具合 | 幕のクリア後「ここで冒険を終える」を1回タップすると即終了（続きは遊べない）。→確認ダイアログ。 |
| 不具合 | ボスレリックは1タップで確定し、説明を読んだり比べたりできなかった。→タップで選択、「これに決める」で確定。 |
| 不具合 | X（エナジーを全部使う）カードは「使う」を押した後に取り消せなかった。→送る前にXを選び、「やめる」で手札に戻せる。 |
| 不具合 | 拡張キャラ（スライムボス等）で冒険を終えると、使われない解放ボックスに数が入っていた。→無色カード／第4幕へ割り当て。解放状況画面にも「カードは最初からすべて使える」と表示。 |
| 不具合 | 結果画面で余ったボックスの割り当てボタンが、再描画まで出ないことがあった。 |
| 分かりにくい | ネオーの祝福（Downfallではハートの恩恵）で何が変化したのか分からないまま戦闘が始まっていた。→イベントと同じ「結果」画面を表示。 |
| 分かりにくい | カード報酬・イベント・ボスレリック・商人でデッキを確認できなかった。→「デッキを見る」を追加。デッキ一覧はスマホで3列。 |
| 分かりにくい | マップの凡例が文字だけで、記号と対応していなかった。→マップと同じ記号付き。 |
| 分かりにくい | 選択肢の下の「〜の解説」が選択肢の全文を繰り返していた。→「解説」に短縮（読み上げ用に全文は保持）。 |
| 分かりにくい | ソロの結果画面に「全員：」、商人に「ほかのプレイヤーにゴールドを渡して」と協力用の文が出ていた。 |
| 分かりにくい | 難易度の説明（初心者の内容）を短く正確に。冒険の種類に「はじめての方に／慣れた方向け」。 |

## 検証

- 既存テスト33本＋カード文字の収まり検査（1145面×7サイズ）がすべて通過。
- 新規 `tools/ibara-polish-test.cjs`：ネオー／ハートの恩恵の結果と途中セーブからの再開（二重適用なし）、報酬のゴールド自動受け取りと確認、幕間・あきらめるの確認、ボスレリックの選択→確定（他人が先に取った場合）、デッキ確認、凡例、Xの選択と取り消し、拡張キャラの解放ボックス、もう一度遊ぶ、招待リンク。
- 最新の方針（通常の冒険は基本4キャラ、Downfallは8キャラ）に合わせて古い期待値のテスト3本を更新（`ibara-beginner-test`・`ibara-help-test`・`ibara-downfall-browser-check`）。
