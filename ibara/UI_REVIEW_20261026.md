# 戦闘・強化画面の引き継ぎと確認用変更（2026-10-26）

状態：ユーザーから修正案を反映する承認を受領。サイコロと攻撃予告の分かりにくさもあわせて修正。

## 引き継いだ状態

- 公開版はボードゲームのルールへ書き直したエンジンに、旧世代の戦闘背景・カード・報酬表示を部分的に移植した構成。
- 元の画面構成は `fc41401`（書き直し直前、2026-10-24）から別チェックアウトで再現した。
- 敵味方表示、各キャラクターの向き、用語解説、第2〜4幕、協力プレイのエンジンは維持する。
- 前のWorkの「公式モジュールの盤面4面を使う」作業は、この公開ブランチでは反映されていない。本変更は盤面の公式一致や、ゲーム全体の完全再現を完了させるものではない。

## 画面と確認結果

1. **戦闘**：現行は操作ボタンが手札の下、エナジーが別段になり、カードも小さい。旧世代のように操作を手札の上へ揃え、手札を拡大。左右端のカードが欠けないよう重なり量と余白を修正した。敵味方の表示を残した。
2. **選択中のカード**：持ち上げ・拡大表示と操作欄がHPや敵を覆っていた。効果本文と「使う・戻す」を専用の行に置き、手札は小さく持ち上げるだけに変更。重複する「使う」を削除した。
3. **カード強化**：現行は選んだカード自体が強化後へ置き換わり、決定ボタンが長い一覧の下へ流れる。旧世代の枠付き選択画面を参考に、一覧だけをスクロール可能にし、強化前後の比較と決定操作を常に表示。選択だけではゲーム状態を書き換えず、確定後にだけ送信する。
4. **デッキ・敵などの詳細**：閉じるボタンが一覧の末尾にしかなかった。上部に固定表示し、背景タップとEscapeでも閉じられるようにした。用語解説を閉じるEscapeが下の情報画面まで閉じないようにした。必須のゲーム選択は閉じない。
5. **マップの情報**：移動不可のノードを押しても反応しないハンドラを修正し、部屋名の情報を開くようにした。
6. **拡大**：viewportのズーム禁止指定を外した。

## 承認後の追加修正：行動ダイスと攻撃予告

- サイコロに「行動ダイス」の常時ラベルを付け、出目が敵の行動や一部の効果を決めることを戦闘画面に表示。
- 各敵に「出目3→3〜4の行動」「行動順」「毎回同じ」などの決まり方、攻撃対象、ダメージ・連撃回数・合計を表示。
- ブロックで防ぐ前のダメージであること、敵が動くタイミングを常時表示。
- サイコロをタップすると仕組みと、今回の敵の行動一覧が実際の行動順で開く。
- 敵をタップした詳細に現在の予告と行動表を表示。関数が毎回別の行動オブジェクトを返す敵で、今回の行が強調されない不具合を修正。
- 協力プレイでは敵の全体攻撃・列攻撃の対象と、対象ごとの弱体化・好奇心による違いを区別。
- 予告は現在の状態で計算し、実際のHP減少の確定値とは扱わない。先に行動する敵の効果やカード・状態で値が変わる旨を詳細に記載。
- `ibara-intent-test.cjs` で実際のエンジンが出す攻撃イベントと予告を照合（11ケース）。連撃、脱力・弱体化、対象別補正、ガーディアンの条件付き攻撃、出目の範囲、行動表の強調、ゲーム状態不変を検証。
