# The・Island

Exploration game for the PLAYROOM shelf: survey the plants and creatures of an island that
appeared overnight, extend a radio relay network with antennas, reach the caldera at its heart
and call the helicopter home. Single player or co-op (up to 4, PeerJS room codes).

Public URL: https://rkkrk18941.github.io/compile-game/island/

## Layout

- `src/` – game source (three.js r186), bundled into `index.html` by `npm run build:island`.
  - `core/` engine, quality tiers, input, asset loading
  - `gfx/` shader patches (atmosphere, canopy light, wind, leaf translucency), sky, post
  - `world/` terrain (GPU CDLOD), ocean, foliage (instancing, LOD, impostors), ground cover
  - `game/` gameplay: explorer, creatures, survey, radio network, helicopter, props, save
  - `ui/`, `audio/` (synthesised), `net/` (co-op)
- `blender/` – every asset is generated by these scripts with Blender 5.2 (the `bpy` module):
  `terrain.py`, `materials.py` (ground), `palms.py`, `trees.py`, `ferns.py`, `understory.py`,
  `impostors.py`, `explorer.py`, `creatures.py`, `props.py`. Field-guide portraits and the
  shelf cover are captured from the game renderer with `tools/island-capture.cjs`.
- `assets/` – generated runtime data (GLB, WebP, height field).

## Rebuilding assets

```sh
python -m venv bpyenv && bpyenv/bin/pip install bpy==5.2.3 numpy scipy pillow numba
bpyenv/bin/python island/blender/terrain.py      # and the other scripts above
npm run optimize:island                          # meshopt-compress the exported GLBs
npm run build:island
```

`impostors.py` reads uncompressed GLBs, so run it before `optimize:island`.
`materials.py --detile-existing` re-applies only the de-tiling step to already exported ground
layers (the bake applies it itself).

## Field-guide portraits and the shelf cover

```sh
node serve.js &                                   # http://localhost:8788
npm run build:island -- --dev
node tools/island-capture.cjs portraits [ids...]  # island/assets/portraits/<id>.webp
node tools/island-capture.cjs cover               # games/img/island(.webp|-640.webp)
```

Each subject is photographed in the game world: it is framed from its real bounds (animals by
their head bone, in a held pose), the camera takes the side with the sun behind it and clear
ground, plants between lens and subject are pushed aside for the shot, and a soft fill flash
lifts subjects in the shade of the canopy. Per-subject settings are in `SHOTS`, the cover
composition in `COVER` (try framings quickly with `COVER_TEST=1 COVER='{"cam":[...]}'`).
