# 巨獣黙示録

ブラウザで巨獣を育成・改造し、中世の王国へ侵攻させるゲーム。
公開先は `https://rkkrk18941.github.io/compile-game/kyoju/`。セーブキーは既存の `kyoju-mokushiroku-v1` を維持。

## ビルド・検証

```
npm ci
npm run build:kyoju
npm run test:kyoju
```

`kyoju/index.html` は Three.js と育成画面を内蔵した成果物。ソースは `kyoju/src`。ビルド用に新しい外部依存は追加していない。

## 2026-11-02 描画改修

- 地形生成の毎フレーム40msの設定を廃止。通常フレームは1チャンクまで生成する。1チャンク自体の処理時間は端末性能に依存する。
- タイルの距離判定をキャッシュの有無から独立させ、LODの往復切り替えを抑制。細分化の閾値に余裕を設け、親子タイルの同時表示を防止。新しいタイルの高さを親タイルから0.35秒かけて補間する。
- 開始地点の地形と木をローディング中に準備し、シェーダーの非同期コンパイルを実行。
- 木を近景・遠景の2段階に分け、近くから本数上限内で配置。生成を小分けにし、完成まで既存の森を維持。毎回描画半径を増減させる処理を廃止。
- スマホでは影・木・粒子の予算を下げ、負荷が続いた場合だけ解像度を段階調整。復帰には長い安定期間を要求する。
- 毎回の環境マップ再生成を廃止。太陽と霧・明るさは時間に追従し、影を光の座標系でピクセルに合わせる。
- 窓・瓦・畑・皮膚などの細部を距離に応じて平均化。高画質のブルーム後にFXAAを追加。露出と発光を抑えた配色、軽量設定でも使える柔らかい接地影を追加。
- 戦闘の追いつき処理に上限を設定。処理落ち時にはゲーム内時間が遅くなる場合がある。出来事を飛ばして進めない。
- 画面揺れは初期OFF。一時停止、解像度自動調整、揺れ、移動早回し、FPS表示、ゆっくり周回するカメラ、操作表示の非表示を侵攻中の「画面」に追加。
- 背景に移った際の戦闘と描画を停止。3D表示中は育成画面の2Dアニメーションを停止。終了時にジオメトリ・材質・テクスチャ・描画先・骨格・入力リスナーを解放する。
- WebGLのコンテキスト消失中は戦闘を止め、復旧時に環境マップを再生成。起動失敗時は記録を保持して軽量設定で再試行できる。

## 確認済みと未確認

回帰確認8項目が成功。地形の全域被覆と親子非重複、静止時の収束、木の本数制限と生成途中の維持、11種のモデル生成と歩行、2種の実戦・建物破壊・撤退、セーブ継続を確認。

森林の固定検証場面では889本、171,594三角形。同じ本数を詳細モデルで表現した参考値704,088三角形に比べ約76%削減。画面全体の削減率や実機FPSを表す数値ではない。

操作画面は390×844と844×390の領域で、画面設定・チェックボックス・一時停止・操作表示の切り替えをブラウザで確認した。

検証用ブラウザはWebGLを無効化しており、3Dの実映像・GPUシェーダー実行・実機FPS・ちらつきの解消は未確認。AAA作品と同等のアセット品質やパフォーマンスを保証するものではない。実機で昼夜・戦闘・全視点・ズーム・再侵攻を確認する必要がある。
