# 怪物の造形・動きの再制作：猟犬の単体試作

このブランチは造形確認用です。公開版への反映、全怪物と隊員の置換、添付参照水準への到達を意味しません。

![猟犬の造形確認](hound-v2.png)

[動きの確認映像](hound-v2.mp4)

映像はBlenderの確認用照明によるレンダリングです。ゲーム映像ではありません。使用するメッシュ・骨格・各フレームの関節変換は、実行時モデルとゲームのアニメーション処理から取得しています。

## 今回の実装

- 30関節：肩帯と骨盤、前後で曲がる方向の違う四肢、2節の首、下顎、6節の尾。
- 胴体・筋肉・四肢を一つの皮膚へ融合し、関節周辺を最大4関節のウェイトで連続変形。編集可能なBlender原本とゲーム向けデータを保存。
- 上下の歯列、口腔、眼窩・縦瞳孔、部位ごとの鱗、鰓の軟骨と発光糸を実形状で制作。
- 移動距離に基づく歩行、ワールド座標での接地、2関節IK、急停止・旋回時の踏み直し、重心の上下・左右移動、首の注視と尾の遅れ、噛みつき前の溜め。
- 近距離106,896三角形、遠距離19,240三角形。同じ骨格を共有して切り替え。

## 確認

`node tools/noclip/regression.mjs`：既存302項目を通過。

`node tools/noclip/hound-review.mjs`：待機・歩行・加速・攻撃の144フレーム、接地IK576回、固定接地215区間を確認。高速旋回・傾斜・瞬間移動で接地1,589回も確認。両LODの関節番号とウェイト合計も検査。

GPU上の実描画、実機負荷、複数端末での描画は未確認です。映像と数値検査は、写実性や自然さの完成判定の代用にはしません。

## 続けて必要な制作

この1体にも、目と口の周囲の表情、関節の皮膚の潰れ、鱗の不規則性、鰓の軟体変形など、参照に対して不足が残ります。他の16種類の怪物、6種類の隊員、部屋も同様の品質へ作り直す必要があります。これらを完了扱いにしません。

## 再生成

1. Blender 4.5で `tools/blender/anatomy-hound.py -- REPO` を実行。
2. `node tools/noclip/hound-review.mjs` でゲーム側の動きを採取。
3. Blenderで `tools/blender/review-hound.py -- REPO` を実行して静止画、`--video` で連番を出力。
4. `npm run build:noclip` で実行時コードをビルド。

`REPO` はこのリポジトリの絶対パスです。静止画と連番の出力先は `.tmp/anatomy/`、原本は `../hound.blend` です。
