# 風の怪物ピラデロ — このアプリのルールと判断

ボードゲーム「風の怪物ピラデロ」（Piradero The Wind Creature／制作：Dragon Create、ゲームデザイン：桃居土 竜、イラスト・DTP：TOM DESIGN、2025年秋）の
ルールで遊べる、個人で遊ぶための非公式版です。カード絵は原作の公開資料を参考に再描画した非公式のものです。原作の印刷データそのものではありません。歯車・鍵・テーブルはこのアプリ用のモデルです。

## 調べたルール（公式の説明書シートより。言い回しはこのアプリ用にまとめ直しています）

| 項目 | 内容 |
|---|---|
| 人数 | 2〜3人 |
| カード | 10枚。0〜9が1枚ずつ。0は「蒼き眼の怪物」、9は「紅き眼の怪物」、1〜8は通常カード |
| 歯車 | 各自5個（ライフ）。0個になったら脱落 |
| 鍵 | 1本。持っている人がそのラウンドの最初の手番。最初はジャンケンで勝った人 |
| 準備（3人） | 9枚を場に裏向きで並べ、残り1枚を「風向き判定カード」として少し離して裏向きに置く |
| 準備（2人） | 6枚を場に裏向きで並べ、1枚を風向き判定カードにする。残り3枚は使わない（だれも見ない） |
| 風向き判定カード | だれも見ることも取ることもできない |

### 1ラウンドの流れ（鍵を持つ人から時計回り）

1. **手札選択**：手番の人は場札を1枚えらんで自分だけ見る。そのあと場札を1枚えらんで手札にする（見たカードと違ってもよい）。
   次の人へ。これを2周して全員の手札を2枚にする。場札は人数と同じ枚数だけ残る。
2. **逃亡**：残った場札をすべて表にする（風向き判定カードは表にしない）。鍵を持つ人から順に、場札と自分の手札を見て「戦う」か「逃げる」を選ぶ。
   逃げた人は歯車を1個失い、そのラウンドの残りには参加しない。戦う人が1人だけなら、その人の不戦勝。
3. **戦闘**：戦う人は全員手札を公開する。手札の合計が小さい人から順に、場に残っている一番大きい数字のカードを受け取り、手札を3枚にする
   （合計が同じなら手番が先の人から）。3人プレイで戦う人が2人のときは、場札の一番大きいカードと一番小さいカードを受け取り、真ん中のカードは場に残す。
4. **風向き判定**：風向き判定カードを表にする。
   - **0か9（怪物）なら、手札の合計が小さい人の勝ち**
   - **1〜8なら、手札の合計が大きい人の勝ち**
   - 合計が同じなら、手番が先の人の合計が大きいとみなして判定する

   負けた人は歯車を2個失う。0個になった人は脱落。勝った人が鍵を受け取って次のラウンドへ。3人プレイで1人脱落したら、次のラウンドから2人で続ける。

**勝利**：自分以外の全員の歯車を0にした人の勝ち。

### このルールのおもしろいところ

合計が小さい人ほど大きい場札をもらうので、手札が強すぎると逆転される。2人なら、合計の差が場札2枚の差より大きいときだけ「大きい人」が勝ちを守れる。
さらに風向き判定カードが0か9だと勝ち負けがひっくり返る。2人プレイでは自分から見えないカードが6枚あり、0と9がどこにあるかで風向きの確率が変わる。

## 原文に書かれていなかったことの扱い

- **見るのは毎手番かならず1枚**：説明書の順番どおり「見る → 取る」。すでに見たカードをもう一度見てもよい（意味はないので画面では勧めない）。
- **だれがどのカードを見たか・取ったかは全員にわかる**：実物でもカードを持ち上げる手元は見えるので、場札に「見た人」の印を付ける。数字は見た本人にしかわからない。
  自分が見たカードを相手が取ったときは、相手の手札のその1枚に数字を小さく表示する（自分が知っている情報なので）。
- **逃亡の選択は1人ずつ順番に、全員に見える**：「鍵を持つプレイヤーから順に」なので、後の人は前の人の選択を見て決められる。
- **自分より前の全員が逃げたら、最後の人は自動で不戦勝**：最後の人が逃げても歯車を失うだけなので、選ばせずに不戦勝にする。
- **不戦勝のときは風向き判定カードを表にしない**：戦闘と風向き判定のフェーズが行われないため。逃げた人の手札も公開しない。
- **歯車は0より減らない**：1個の人が負けても0個（脱落）。脱落の処理はラウンドの終わりにまとめて行う。
- **鍵**：勝った人（不戦勝を含む）が受け取る。ラウンドの勝者は必ず生き残るので、鍵を持つ人が脱落することはない。

## このアプリでの見せ方

- テーブルは3D。場札は中央、風向き判定カードは横の羅針盤の台、各自の前に歯車、鍵を持つ人の前に鍵。
- 自分が見たカードには目の印と数字（自分の画面だけ）。ほかの人が見たカードにはその人の色の目の印。
- 逃亡フェーズでは「戦う」「逃げる（歯車−1）」の大きなボタン。画面上部にいつでも「1〜8：大きい方が勝ち／0・9：小さい方が勝ち」を表示。
- ラウンドの結果は、手札・受け取ったカード・合計・風向き・歯車の増減を一覧で見せ、「次のラウンドへ」を押すまで止まる（速すぎないように）。
- 歯車の数は5個（原作）のほか、3個（短め）・7個（長め）も選べる。最初に鍵を持つ人は「ジャンケン（ランダム）」か「あなた」。

## CPU

3段階（やさしい・ふつう・つよい）。どのCPUも、その席から見える情報（自分の手札・自分が見たカード・表になった場札・だれがどこを見て何を取ったか・前の人の選択）だけで決める。
見えないカードは「ありうる配り方」をすべて数え上げて（2人なら最大60通り、3人なら最大30通り）勝つ確率を出す。

- **やさしい**：見るカードはでたらめ。見たカードが大きければ取る。戦うかは大まかな勝率に迷いを足して決める。
- **ふつう**：取るカードごとに、残りの手番をシミュレーションして勝ちやすいカードを取る。逃亡は勝率と歯車の数から決める。
- **つよい**：「見たカードを取ったか、見送ったか」からほかの人の手札を推理して配り方に重みをつける。どのカードを見ると判断が一番よくなるかで見る場所を選ぶ。
  後の人が逃げるかどうかも読んで、強気に戦う（はったり）ことがある。歯車の残りからこの勝負の重さ（脱落の危険）を計算する。
