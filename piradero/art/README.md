# Card face artwork

`card-atlas.webp` is an AI-assisted redraw using the supplied photo and public product/design references. It is not the original print file. Ten card fronts, ranked 0–4 across the upper row and 5–9 across the lower row. `cards.js` records the measured cell bounds and renders the same artwork for the 3D table, flat fallback, hand thumbnails, results and gallery.

Original game: Dragon Create. Game design: 桃居土 竜. Original illustration and DTP: TOM Design.

References:
- https://gamemarket.jp/game/186333
- https://img.gamemarket.jp/20251016_001321_G3QfKufbMAALEJI.jpg
- https://note.com/tom__design/n/n4994be854674

The redraw follows the ivory paper, sepia mechanical prehistoric creatures, charcoal gear corners, small corner ranks, and blue/red monster eyes shown in these references. Source photos and presentation sheets are not distributed in the application.
