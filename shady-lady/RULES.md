# シェディー・レディー（Shady Lady）— このアプリのルールと判断

ボードゲーム「シェディー・レディー」（ゲームデザイン：宮野華也、アートワーク：別府さい、発売：モブプラス／Mob+、2025年）の
ルールで遊べる、個人で遊ぶための非公式版です。画面・カード・箱のデザインはこのアプリ用のオリジナルで、原作の絵やロゴは使っていません。

## 調べたルール

| 項目 | 内容 |
|---|---|
| カード | 80枚。1〜4と6〜9が各10枚。**5はない**。スートなし |
| 得点チップ | 13枚（6人で全員2点＋1人3点まで足りる数）。アプリでは金色のチップで表示 |
| 準備 | よく切って各自3枚。残りを山札に |
| 手番 | 時計回り。次の4つから1つ |
| A. 引く | 山札から1枚引き、手札から1枚を自分の捨て札の上に表向きで捨てる |
| B. 取る | だれかの捨て札（自分のも可）の一番上を取り、1枚を自分の捨て札に捨てる |
| C. トライ | 役があるときだけ。手札を公開して役を言う。ほかの人は時計回りに、**すでに公開された役より強い**ときだけ公開してよい。トライした人の右隣が公開するかしないかを決めたら終わり。一番強い役の人が1点。公開した人は全員、好きな順で自分の捨て札に置き、新しく3枚引く |
| D. ジャック | 1人を指名し、その人は手札を公開する。役があれば指名した人が1点、なければ指名された人が1点。指名された人は（結果にかかわらず）好きな順で自分の捨て札に置き、新しく3枚引く |
| 役 | ゾロ目（同じ数字3枚）と連番（続く数字3枚）。ゾロ目はどの連番より強い。同じ種類なら数字が大きいほうが強い（例：1-2-3 ＜ 7-8-9 ＜ 6-6-6） |
| 山札切れ | 各自の捨て札は一番上の1枚だけ残し、残りを集めて切り、新しい山札にする |
| 勝利 | 3点取った人がその場で勝ち |

5がないので、連番は 1-2-3・2-3-4・6-7-8・7-8-9 の4種類だけ（4と6は続いていない）。役は全部で12種類。

## 原文に書かれていなかったことの扱い

- **同じ強さの役**：トライに応じて公開できるのは「より強い」役だけなので、同じ強さでは公開できない（先に出した人が勝つ）。
- **トライやジャックのあとの手番**：「行動のあと次の人へ」なので、トライ・ジャックを**した人の次の人**から。
- **捨てる順番を決める順**：公開した人それぞれが決め、全員が決まってから同時に捨て札へ置き、その後トライした人から時計回りに3枚ずつ引く。
- **山札を作り直すタイミング**：山札から引く必要が出たときに山札がなければ作り直す（トライ後の3枚補充の途中でも同じ）。
- **自分の捨て札の一番上を取って、それをそのまま捨てる**：禁止されていないので可能。
- **応じられる役を持っていてもパスしてよい**：「公開してもよい」なのでパス可。パスした人の手札はそのまま。

## このアプリでの見せ方

- 捨て札の山は、上から5枚が見えるように少しずらして置く（記憶の代わり。全部の流れは「記録」で見られる）。名前をタップすると、その人の捨て札と、新しい手札になってからの動き（何を取って何を捨てたか）が見られる。
- だれが捨て札から何を取ったかは公開情報なので、その人の札に表示する。山札から引いたカードと、引いたカードをそのまま捨てたかどうかは見せない。
- 自分の番に役があるとトライボタンが光る。トライへの応答は自分で「公開して勝負」か「パス」を選ぶ。より強い役がない場合は理由を表示し、「パス」を押して進む。
- 勝利点は3点（原作）のほか、4点・5点も選べる。

## CPU

3段階（やさしい・ふつう・つよい）。どのCPUも、その席から見える情報（自分の手札・全員の捨て札・捨て札から取られたカード・最近の動き）だけで決める。
ほかの人の手札は「見えていないカードの残り枚数」からありうる組み合わせを全部数えて見積もり、
つよいは「その人が直前に何を取って何を捨てたか」「トライをパスしたか」からも推理する。
トライは「だれかにもっと強い役で返される確率」、ジャックは「その人が役を持っている確率」で決める。

## 4枚版（アプリ独自ルール）

開始設定で3枚（原作）／4枚版を選択できる。オンラインではホストが設定し、全員に適用される。

- 配札・補充は4枚。引く／取ると5枚になり、1枚捨てて4枚に戻す。
- 役は手札4枚すべてで作る。同じ数字4枚のゾロ目、または1-2-3-4／6-7-8-9の連番。3枚だけの役は認めない。
- ゾロ目は連番より強い。同種なら数字が大きい方が強い。同じ強さ以下の役ではトライに応じられない。
- トライ・ジャック・得点・捨て札の順序・勝利条件は3枚版と同じ。公開した人は4枚すべて捨て、新しく4枚引く。
- CPU、保存・再開、再戦も選んだ枚数に従う。
