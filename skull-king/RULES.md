# スカルキング（Skull King のルール）仕様

ブラウザ版 `skull-king/` が実装しているルールと、その根拠です。
資料の確認日は 2026-10-21 です。各項目の［ ］は下の「出典」の番号です。
ルールの判定はすべて `engine.js` にあり、`tools/skullking-rules-test.mjs`（991項目）と `tools/skullking-browser-check.mjs`（実ブラウザでの通し対戦：スマホ4人・2人と白ひげの幽霊・PC8人、続きからの再開、2つのタブでのオンライン対戦、海賊5人の能力、5つの画面サイズで10枚の手札が画面に収まること）で確かめています。CPUの強さは `tools/skullking-selfplay.mjs` で比べられます。

## 対象と版

- 原作は Brent Beck、Jeffrey Beck のカードゲーム『Skull King』。現行の Grandpa Beck's Games 版（2〜8人、プレイカード74枚）を対象にしています［1］［2］。日本語版はリゴレから2022年8月に発売（翻訳：今井恵利）［9］。
- 旧版（Schmidt 版／スカルキング・レジェンド：数字1〜13、66枚、2〜6人、マーメイドでスカルキングを取ると50点など）とは得点と構成が違います。このアプリは新版のルールだけを扱います［10］。
- カードの絵はこのアプリのために描いたもので、製品のイラストは使っていません。カード名は日本語版の呼び方（逃走・海賊・ティグレス・スカルキング・マーメイド・クラーケン・白クジラ・略奪品・白ひげの幽霊）に合わせました［9］［11］。日本語版での海賊5人の名前は確認できなかったので、英語名をカタカナにしています。

## カード（74枚）［1］［2］

| 種類 | 枚数 | このアプリでの名前 |
|---|---|---|
| 数字カード | 4色×1〜14＝56 | 黄（宝箱）・紫（地図）・緑（オウム）・黒（海賊旗＝切り札） |
| 逃走 | 5 | 白旗 |
| 海賊 | 5 | ロージー・ディレイニー、盗賊ベント、ロアタンのラスカル、フアニータ・ジェイド、巨人ハリー |
| ティグレス | 1 | 出すときに海賊か逃走を選ぶ |
| スカルキング | 1 | |
| マーメイド | 2 | （新版のカードに名前はない［2］） |
| クラーケン・白クジラ・略奪品×2 | 4 | 追加ルール（上級ルール）でだけ使う |

基本は70枚。追加カードを入れると最大74枚。

## 準備・ラウンド

- 全10ラウンド。第Nラウンドは各自N枚。ラウンドの最初に全カードを集めて切り直す［2］。
- ラウンドの最初のリードは「親の左の人」で、親は毎ラウンド左へ移る。アプリでは最初のリードをランダムに決め、毎ラウンド左隣へ移します［2］。
- 7人なら70枚でちょうど10枚ずつ配れる。8人は足りなくなるので、最後のほうのラウンドは配れる最大枚数をくり返す（基本70枚なら第9・第10ラウンドも8枚）［2］［3］［4］。アプリは「デッキ枚数÷手札の数」の切り捨てを上限にしています（追加カード4枚を入れた8人戦は9枚まで）。
- ラウンド構成の選択ルール［2］：波おだやか（Even Keeled：2・2・4・4・6・6・8・8・10・10）、いきなり大乱闘（Skip to the Brawl：6〜10枚の5ラウンド）、さくっと小競り合い（Swift-n-Salty Skirmish：5枚×5）、一斉砲撃（Broadside Barrage：10枚×10）、大渦（Whirlpool：9・9・7・7・5・5・3・3・1・1）、寝る前の1回（Past Your Bedtime：1枚×1）。日本語名はこのアプリでの訳です。

## ビッド

- 手札を見て、取れるトリック数を全員が同時に宣言（「ヨー・ホー・ホー！」の3回目で公開）。0から手札の枚数まで。公開後は変更できない［2］［8］。
- アプリでは各自が非公開で決め、全員そろったところで同時に公開します。

## トリック

- リードから時計回りに1枚ずつ。いちばん強いカードの人がトリックを取り、次のリードをする［2］。
- **マストフォロー**：数字カードがリードされたら、同じ色を持っていればその色を出す（黒がリードされたら黒）。持っていなければ何を出してもよい［2］［4］［8］。
- **特殊カードはいつでも出せる**（同じ色を持っていても）［4］［5］。
- **逃走・逃走のティグレス・略奪品がリードされたとき**：次の人が出したカードが色を決める。その人も特殊カードなら、決める役はさらに次へ移る［2］［3］。公式FAQ：略奪品のリードは逃走と同じ［1］。
  - 逃走のあとに海賊などのキャラクターが出た場合について、英語版の説明書ははっきり書いていません。イタリア語版の説明書は「色はその後に出た特殊カードでない最初のカードが決める（特殊カードならさらに次へ）」と書いているので［3］、このアプリは「最初に出た数字カードの色に従う」で実装しています。
- **海賊・海賊のティグレス・スカルキング・マーメイド・クラーケン・白クジラがリードされたとき**：そのトリックは色の指定なし［2］［1］。
- トリックの途中で出た白クジラ・クラーケンは、決まった色を消さない（公式FAQ）［1］。

### 強さ［2］［4］［5］

1. **スカルキング**：数字カードと海賊（海賊として出したティグレスも）に勝つ。負けるのはマーメイドだけ。
2. **海賊**：数字カード（黒も）とマーメイドに勝つ。海賊どうし（ティグレス含む）は先に出した方。
3. **マーメイド**：数字カードとスカルキングに勝つ。海賊に負ける。マーメイドどうしは先に出した方。
4. **黒（海賊旗）**：ほかの色の数字に勝つ。黒どうしは大きい方。
5. **リードされた色**の大きい方。ほかの色は勝てない。
6. **逃走**：必ず負ける。

- **海賊・スカルキング・マーメイドが同じトリックにそろったら、出した順に関係なくマーメイドの勝ち**（公式FAQ・説明書）［1］［2］。
- **全員が逃走（逃走のティグレス・略奪品を含む）なら、最初に出したカードの勝ち**［2］。
- ティグレスは出すときに海賊か逃走かを宣言する［2］。

## 得点

### スカルキング式（標準）［2］［4］［5］［6］

| | 結果 | 点数 |
|---|---|---|
| ビッド1以上 | ぴったり | ビッド×20 |
| ビッド1以上 | 外れ | ずれた数×−10（多くても少なくても） |
| ビッド0 | ぴったり | 手札の枚数×10 |
| ビッド0 | 1トリックでも取った | 手札の枚数×−10 |

「手札の枚数」は、そのラウンドに配られた枚数（8人戦や選択ラウンドでは配った枚数）です［2］。

### ボーナス（ビッドがぴったりのときだけ）［2］［4］［5］

- 取ったトリックの中の14：黄・紫・緑は1枚10点、黒は20点。自分が出した14も数える［2］［3］。
- 海賊で取ったマーメイド：1枚20点。
- スカルキングで取った海賊：1枚30点（海賊として出したティグレスも。逃走として出したティグレスは0点：公式FAQ）［1］。
- マーメイドで取ったスカルキング：40点。
- 出した順番は関係なく、取ったカード（トリックに勝ったカード）で判定する［2］［3］。海賊・スカルキング・マーメイドがそろったトリックはマーメイドの40点だけ（説明書の例：黄の14・海賊・スカルキング・マーメイド → 40＋10＝50点）［2］［6］。
- 略奪品の同盟：2人ともビッドぴったりなら、それぞれ20点［2］。

### ラスカル式（選択ルール）［2］［7］

- ビッドの大きさに関係なく、全員の「見込み点」が手札の枚数×10点。
- ぴったり（Direct Hit）：全部。1ずれ（Glancing Blow）：半分。2以上ずれ（Complete Miss）：0点。ボーナスも同じ割合［7］。公式の例（手札3枚で0・1・2をビッドして全員的中→30点ずつ、手札4枚で的中40点・1ずれ20点・2ずれ0点）をテストにしています。
- 大砲と散弾（選択）：ビッドと同時に選ぶ。大砲はぴったりなら手札の枚数×15点、1でもずれたら0点（ボーナスもなし）。散弾はふつうのラスカル式［2］。
- 略奪品とラスカルの賭けは、ラスカル式でもぴったりのときだけ（公式FAQ）［1］。

## 追加ルール

### クラーケン［1］［2］

- 出たトリックは壊れ、だれも取らない（カードはよける）。
- 次のリードは「クラーケンがなければ勝っていた人」。アプリでは、クラーケン（と白クジラ）を除いた残りのカードでトリックを判定した勝者にしています（公式FAQ：白クジラのあとにクラーケンが出たら「2匹とも出なかったとしたら勝っていた人」）。
- FAQの例「黄12・黒3・白クジラ・クラーケン → だれも取らず、黒3の人が次のリード」をテストにしています。

### 白クジラ［1］［2］

- このトリックの特殊カードは力を失う（逃走あつかい）。数字カードは色がなくなり、いちばん大きい数字の勝ち。同じ数字なら先に出した方。
- 特殊カードしか出ていなければトリックは流れ、白クジラを出した人が次のリード。
- 白クジラの効いたトリックでは、キャラクターのボーナスは出ない（特殊カードは力を失うため）。取った14のボーナスは数える。略奪品も力を失うので同盟はできない（このアプリの解釈）。
- クラーケンと白クジラが同じトリックに出たら、あとに出た方だけが効き、先の方は逃走あつかい［1］。

### 略奪品［2］

- 逃走と同じように扱う。出した人と、そのトリックを取った人が、そのラウンドの間「同盟」になる。2人ともビッドぴったりなら、それぞれ20点。
- 略奪品の人がそのトリックに勝った（ほかがすべて逃走だった）ときは同盟なし［2］。
- 同じ2人が2回同盟したときに20点が2回になるかは説明書にない［11］。このアプリは略奪品1枚ごとに1つの同盟として数えます。
- 2人用ルール（白ひげの幽霊）では使わない［4］。

### 海賊の能力（選択ルール）［1］［2］

- 海賊でトリックに**勝った**ときだけ、その海賊の力を使える（取っただけでは使えない）。すぐに使い、次のラウンドへは持ち越さない。
- 最後のトリックのあとで使えるのは巨人ハリーだけ（公式FAQ）。ほかの海賊が最後のトリックに勝っても能力はなし。
- ティグレスには能力がない。白クジラが効いたトリックでは海賊は力を失うので能力もなし（このアプリの解釈）。

| 海賊 | 能力 |
|---|---|
| ロージー・ディレイニー | 次のトリックを始める人を選ぶ（自分も可） |
| 盗賊ベント | 山札（配られなかったカード）から2枚引き、手札から2枚捨てる。捨てたカードはラウンドの終わりまで場から外れる。山札が足りなければ引けた枚数だけ |
| ロアタンのラスカル | 0・10・20点のどれかを賭ける。ビッドが当たれば獲得、外れれば失う |
| フアニータ・ジェイド | 配られなかったカードをこっそり見る（アプリではそのラウンドの間、見直せます） |
| 巨人ハリー | ビッドを1増やすか1減らす（そのままでもよい）。0未満・手札の枚数より上にはできない |

## 2人のとき（白ひげの幽霊）［2］［4］［1］

- 手札を3つ配り、3つ目は裏向きの山のまま「白ひげの幽霊」のものにする。幽霊はビッドも得点もしない。
- 2人はラウンドごとに交代で最初のリードをする。
- 幽霊はいつも2番目に出す。自分の番が来たら山のいちばん上をそのまま出す（色に従わない）。
- 幽霊が勝ったら次は幽霊からで、2番目はそのラウンドの最初にリードした人、3番目がもう1人［4］。
- 幽霊のティグレスはいつも逃走（公式FAQ）［1］。略奪品は使わない［4］。
- アプリでは、海賊の能力のロージーで選べる相手を2人のプレイヤーに限っています（幽霊は能力の対象にしない）。

## 勝敗

- 最終ラウンドのあと、合計点がいちばん高い人の勝ち。同点は同じ順位として並べます［5］。
