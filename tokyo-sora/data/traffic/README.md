# tokyo-sora/data/traffic — 公開統計で補正した人流・車流の係数（INTEGRATION.md v1）

`manifest.json`（ゲームが読む係数）と `records.json`（元の値・単位・換算式・取得元の記録）は、`tools/tokyo-sora-traffic/update.mjs` で作ります。手で編集しません。

## 現在の状態

**係数はまだ生成していません。** 作成した環境から国土交通省・国土数値情報のサイトに接続できなかったためです。`manifest.json` が無い間、ゲームは現行の地図由来の推定だけを使います（`src/integration.js` は取得できない・空の場合に補正しない）。

生成するには、ネットにつながる環境で：

```sh
cd tools/tokyo-sora-traffic && npm ci
node update.mjs --dry-run   # 列の対応・件数・除外理由を確認
node update.mjs             # manifest.json と records.json をこのフォルダに書き出す
```

## 何が入るか

| 種類 | 元データ | 年度 | 係数の意味 | basis |
|---|---|---|---|---|
| 車（平日） | 令和3年度 道路交通センサス 一般交通量調査（国土交通省）の24時間観測地点 | 2021 | 時間変化の形を観測に合わせる（1日の総量は推定のまま） | observed |
| 人（平日・休日） | 国土数値情報 駅別乗降客数（国土交通省） | 最新年度 | 駅の規模に応じて駅周辺を増減（全時間同じ値） | estimated |
| 人 | 自治体の歩行者通行量調査（共通形式CSV） | 調査ごと | 時間変化の形を観測に合わせる | observed |

- 係数は 0〜4 の無次元で、ゲームの推定に掛けます。ライブの混雑・現在の人数ではなく、画面では「公開統計で補正した推定」です。
- 日交通量・乗降客数を、時間交通量や歩行者数とは扱いません。
- 休日の車の係数は作りません（公表表に休日の時間帯別交通量が無いため）。データの無い地域・曜日・種別は推定のまま。
- センサスの観測地点の位置は公表された地名（丁目・町）の代表点で、数百m程度の誤差があります。

出典・利用条件：「令和3年度全国道路・街路交通情勢調査 一般交通量調査」（国土交通省, 公共データ利用規約 第1.0版）、「国土数値情報（駅別乗降客数データ）」（国土交通省, CC BY 4.0）を加工して作成。各地点の出典は `manifest.json` の `source`・`license` と `records.json` にあります。
